# バックアップとログ

## 保存先

バックアップとログは、プロジェクト直下の次のフォルダに保存します。`Assets/` の外なので、Unity にはインポートされません。

```
<プロジェクトのフォルダ>/RefFixer_Backup/<日時>/
```

`.gitignore` の書き方によっては、このフォルダは Git に入りません。

## 保存するもの

検査や修復をするたびに、日時のフォルダを 1 つ作ります。

| ファイル | 作るとき | 内容 |
|---|---|---|
| `inspection.md` | 検査したとき | 対象と、見つかった問題の一覧 |
| `batch-inspection.md` | まとめて検査したとき | 件数と、Prefab ごとの問題の一覧 |
| `repair.md` | 修復したとき | どのファイルの何行目を、どの GUID からどの GUID に変えたか |
| `recovery.md` | ごみ箱から戻したとき | コピー元、コピー先、結果 |
| `*.prefab` | 修復したとき | 書き換える前の Prefab |

検査だけでもフォルダが増えます。`inspection.md` や `batch-inspection.md` だけのフォルダは、削除してかまいません。

## 修復を元に戻す { #restore }

バックアップの `.prefab` で元のファイルを上書きすると、修復する前に戻ります。

1. 対象の Prefab を Prefab Mode で開いていれば閉じます。
2. `RefFixer_Backup/` から、戻したい修復の日時のフォルダを開きます。どの修復かは `repair.md` で確かめます。
3. フォルダの中の `.prefab` を、元の場所のファイルに上書きコピーします。
4. Unity に戻ると再インポートされます。されないときは、Project ウィンドウで対象を右クリックして Reimport を選びます。

バックアップのフォルダには、元のフォルダの構成は残っていません。同じ名前の Prefab がいくつかあるときは、`repair.md` に書かれたパスで戻す先を確かめてください。

## 戻せないもの

| 操作 | 戻し方 |
|---|---|
| Force Text への変換 | Unity の設定で元のモードに戻します。アセットの保存し直しがもう一度起きます |
| ごみ箱からの復元 | コピーしたファイルを削除します。ごみ箱のファイルは残っています |
| `.unitypackage` のインポート | このツールはインポートしていません。インポートしたものは自分で削除してください |

## repair.md の例

```
## repair
timestamp: …
success: true
method: …
file: Assets/Avatar/Hoodie.prefab
line: 2481
oldGuid: 3f2b…
newGuid: 8ac1…
```

まとめて修復したときは、変えたすべての行の Diff が続きます。
