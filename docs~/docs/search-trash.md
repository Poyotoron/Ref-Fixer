# ごみ箱から探す

探索設定の「モード 3: OS ごみ箱」です。Unity の Project ウィンドウで削除したアセットは、OS のごみ箱に入っていることがあります。このモードは、ごみ箱の中を読むだけで、ごみ箱の中のファイルを削除も移動もしません。

ごみ箱を空にしたとき、Shift+Delete で削除したとき、OS がごみ箱を自動で空にしたときは、見つかりません。

## 対応している OS

| OS | 状況 |
|---|---|
| Windows | 標準のごみ箱（`$Recycle.Bin`）に対応しています |
| macOS / Linux | 処理はありますが、実機では確かめていません |

読めなかった場所は警告として表示します。

## ごみ箱を調べる

「探索設定」の「ごみ箱を調べ直す」を押します。途中でキャンセルできます。

調べた結果は Unity を閉じるまで覚えていて、「候補を探す」で使います。ごみ箱の中身が変わったら、もう一度調べてください。

## 候補の種類

`.meta` も一緒にごみ箱にあるかどうかで変わります。

| 状況 | 表示 | 内容 |
|---|---|---|
| `.meta` があり、GUID が一致する | 確実な復元 | 元のアセットです。GUID を保ったまま戻せます |
| `.meta` が無く、名前だけ一致する | 推測 | 戻しても GUID が変わるので、参照は直りません |
| `.meta` はあるが、本体が無い | 戻せません | ボタンは押せません |

`.meta` が無いファイルを戻したときは、戻したあとに検査し直し、[プロジェクト内の候補](search-project.md)として選んでください。

## 戻す

候補の「ごみ箱からコピーして復元」を押すと、コピー元とコピー先が確認ダイアログに出ます。承認すると次のように動きます。

1. ごみ箱のファイルを残したまま、プロジェクトへコピーします。`.meta` があれば一緒にコピーします。
2. コピー先は元のパスです。元のパスがこのプロジェクトの `Assets/` の中でなければ、フォルダを選ぶダイアログが出ます。選べるのは `Assets/` の中だけです。
3. コピー先に同じ名前のファイルがあるときは、上書きせずに中止します。
4. コピーしたあと、再インポートと再検査が自動で行われます。

`.meta` をコピーしたのに GUID が一致しなかったときは、警告が出ます。再検査の結果を確かめてください。
