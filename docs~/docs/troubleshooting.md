# 困ったときは

## 「参照を検査」が押せない

- ウィンドウの上部に警告が出ているときは、プロジェクトが Force Text になっていません（[Force Text への変換](serialization.md)）。
- 対象を指定していないときも押せません。

## 候補が 1 件も出ない

修復候補のパネルに出る探索の内訳で、理由を確かめてください。

| 内訳の表示 | 対処 |
|---|---|
| 手がかりが「なし」 | 名前が分かっていません。[.unitypackage の索引](search-unitypackage.md)を作るか、[ごみ箱](search-trash.md)を調べると分かることがあります |
| プロジェクト内が「無効」 | 探索設定でモード 1 をオンにします |
| `.unitypackage` 索引が「未構築」 | [索引を作ります](search-unitypackage.md#build-index) |
| この GUID は索引にありません | その `.unitypackage` のフォルダを登録していません。フォルダを追加して索引を作り直します |
| 条件に合う候補がありません | 名前が似ているものがありません |

どこにも元のアセットが無いときは、このツールでは直せません。配布元から入手し直してください。

## 直したのに直っていない

- 同じ GUID を参照しているほかの Prefab は書き換えていません。それぞれ検査して直してください。
- 「再検査後も同じ Prefab グループの問題が残っています」と出たときは、差し替え先が別の Prefab だった可能性があります。[バックアップから戻して](backup.md#restore)、候補を選び直してください。
- 名前一致の `.unitypackage` は、インポートしただけでは直りません。検査し直して、プロジェクト内の候補として選んでください。
- `.meta` の無いファイルをごみ箱から戻したときも、GUID が変わるので直りません。検査し直して選んでください。

## 違うアセットにつないでしまった

修復のたびにバックアップを取っています。[バックアップから戻して](backup.md#restore)ください。

## 「対象 Prefab が Prefab Mode で開かれています」と出る

その Prefab を Prefab Mode で開いたままです。閉じてから修復してください。

## 「検査時の参照位置が現在のファイルと一致しません」と出る

検査のあとに、そのファイルが変わっています。もう一度「参照を検査」を押してから修復してください。

## 索引が消えた

索引は `Library/` の中にあるので、`Library/` を削除すると消えます。登録したフォルダは残っているので、「索引を構築 / 更新」で作り直せます。

## 「主な対応環境は Unity 2022.3 です」と出る

Unity 2022.3 以外で開いたときの注意です。検査は続けられます。

## 報告する

不具合は [GitHub Issues](https://github.com/Poyotoron/Ref-Fixer/issues) に送ってください。次のものがあると調べやすくなります。

- Unity のバージョン
- 何をしたときに起きたか
- 「結果を Markdown でコピー」の内容（アセットの名前が入るので、見せてよいものか確かめてください）
- Console のエラー
